Type families

Three families cover the whole system: display headings, UI/body text, and monospace for HUD readouts and eyebrow labels. Sizes themselves stay per-component (the sim's dense HUD text is intentionally hand-tuned across ~15 sizes from 8–17px and isn't being collapsed into a scale in this pass — see the note at the bottom).

--font-display
Space Grotesk — headings, big metrics
--font-ui
Inter — everything else: body, HUD, buttons
--font-mono
JetBrains Mono — eyebrow labels, TACREF grid refs

Retrofitting every existing font-size declaration in sim_style.css into a formal scale was intentionally scoped out of this pass — those sizes are pixel-tuned for a dense HUD and touching all of them risked visual regressions for no real benefit. This page documents the intended scale for new components going forward.
